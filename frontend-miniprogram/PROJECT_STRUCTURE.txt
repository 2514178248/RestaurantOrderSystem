=================================================================
                         关键路径说明
=================================================================

✨ 数据流向:
   前端 (Page) ↔ Storage (本地存储) ↔ Backend API

📱 页面导航流:
   index (首页) 
   ├→ cart (购物车) → order-confirm (订单确认) → payment-success (成功)
   ├→ meal-location (取餐地点编辑)
   ├→ order-detail (订单详情)
   └→ user-center (用户中心) → order-list (订单列表) → order-detail

🛠️ 工具调用:
   Pages → Storage.js / API.js ← HTTP.js ← Backend Server

📊 数据持久化:
   购物车     → wx.storage.setItem('cart_items')
   用户信息   → wx.storage.setItem('user_info')
   订单历史   → wx.storage.setItem('order_history')
   取餐地点   → wx.storage.setItem('meal_location')
